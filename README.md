# Jason Ye — Portfolio

My personal portfolio: an isometric world you walk around as a chicken, with
a landmark for each part of my résumé and a gallery of projects.

Built with [Next.js](https://nextjs.org) and React, and drawn on a canvas.

## Running it

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.

## Privacy

The site sets no cookies, has no analytics and loads nothing from third
parties at runtime. The font is bundled with the site at build time. The
only thing stored in the browser is the visitor's own settings (theme,
minimap and so on) in `localStorage`, which never leaves their device.
